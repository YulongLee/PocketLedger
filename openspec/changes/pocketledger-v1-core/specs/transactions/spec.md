# Transactions

## ADDED Requirements

### Requirement: Bill list
The app MUST provide month selection, search, type/category filters, date grouping, empty states, and pagination-compatible loading.



#### Scenario: Basic behavior
- **WHEN** the user uses this capability with valid data
- **THEN** the app completes the requested action and preserves the documented state
### Requirement: Edit and delete
The app MUST provide detail, edit, and delete actions with confirmation; delete failure MUST restore the row.


#### Scenario: Basic behavior
