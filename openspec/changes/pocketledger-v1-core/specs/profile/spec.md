# Profile

## ADDED Requirements

### Requirement: Profile and settings
The app MUST provide user profile, default ledger/account, category management entry, reminders/settings entry, and about/help entry.



#### Scenario: Basic behavior
- **WHEN** the user uses this capability with valid data
- **THEN** the app completes the requested action and preserves the documented state
### Requirement: Data ownership
The app MUST provide data export and destructive data deletion behind explicit confirmation, and explain local/cloud data scope.


#### Scenario: Basic behavior
- **WHEN** the user uses this capability with valid data
- **THEN** the app completes the requested action and preserves the documented state
