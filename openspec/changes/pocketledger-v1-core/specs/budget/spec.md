# Budget

## ADDED Requirements

### Requirement: Budget overview
The app MUST show monthly budget, used amount, remaining amount, and usage percentage.



#### Scenario: Basic behavior
- **WHEN** the user uses this capability with valid data
- **THEN** the app completes the requested action and preserves the documented state
### Requirement: Category budgets
The app MUST show category budgets with progress and distinguish under-80%, warning, and over-budget states without making the whole screen red.


#### Scenario: Basic behavior
- **WHEN** the user uses this capability with valid data
- **THEN** the app completes the requested action and preserves the documented state
