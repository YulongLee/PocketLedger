# Home

## ADDED Requirements

### Requirement: Home summary
The app MUST show the selected month's expense, income, and balance, with balance equal to income minus expense.

#### Scenario: Normal month
- **WHEN** the home data loads with valid records
- **THEN** the app shows all three totals and the selected month.

### Requirement: Home shortcuts
The app MUST expose working shortcuts for bills, budget, reports, and assets.



#### Scenario: Basic behavior
- **WHEN** the user uses this capability with valid data
- **THEN** the app completes the requested action and preserves the documented state
### Requirement: Recent bills and trend
The app MUST show recent records in occurred-at descending order and a trend visualization with a retryable error state.


#### Scenario: Basic behavior
- **WHEN** the user uses this capability with valid data
- **THEN** the app completes the requested action and preserves the documented state
